# ИИ-помощник «Афина» — архитектурные варианты

Черновики архитектуры для будущего чат-ассистента (BACKLOG.md → «Позднее» → «ИИ-помощник»).
Ни один из этих планов ещё не реализован в коде — это только дизайн-документы, чтобы не
терять проделанную работу при смене решения по провайдеру.

## Текущее решение (на момент последней правки)

**Anthropic Claude (Sonnet 5), свой бэкенд (Supabase Edge Function).**
См. [`anthropic-design.md`](./anthropic-design.md).

## Альтернатива, рассмотренная и отложенная

**Google Gemini (платный тариф, минимальный расход)** — рассматривалась ради экономии,
но при уже принятом решении платить в любом случае Anthropic проще и без риска сломаться
от смены API Gemini (Interactions API, breaking changes в мае/июне 2026 — см. документ).
См. [`gemini-design.md`](./gemini-design.md), включая находку про приватность:
**бесплатный тариф Gemini использует контент для обучения моделей**, платный — нет.

## Общее для обоих вариантов (не зависит от провайдера)

- Телефон выполняет весь цикл tool-use против локальной SQLite — бэкенд никогда не читает
  финансовые данные пользователя из Postgres напрямую (иначе пришлось бы дублировать всю
  денежную математику — проценты, налоги, конвертацию валют, план/факт — на сервере,
  создавая второй источник истины, который будет расходиться с приложением).
- Ассистент только читает и предлагает записи (доход/расход, перевод, долг, план,
  разделение счёта) — ничего не пишет сам, всё через экран подтверждения (как черновики
  SMS/push уже работают).
- История чата и черновики — только на устройстве, не синхронизируются (как raw-текст SMS
  сейчас), кроме отдельной таблицы логов использования на бэкенде (без доступа клиента).
- Разделение счёта (сплит-билл): полная сумма чека — расход с вашего счёта, плюс по одному
  долгу «мне должны» на каждого участника; долг без указанного срока — по умолчанию +30 дней.
- Имя ассистента — «Афина», обращение на «вы», нейтрально-деловой тон.
- Ни один из write-тулов не обновляет/удаляет/сторнирует существующие записи в v1 — только
  создание.
