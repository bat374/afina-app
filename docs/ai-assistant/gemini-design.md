# ИИ-помощник «Афина» — план на Google Gemini API (отложенный вариант)

Рассматривался как способ снизить стоимость до $0 (бесплатный тариф). Отложен в пользу
Anthropic (см. `anthropic-design.md`), потому что при уже принятом решении платить в любом
случае Gemini не даёт преимущества, а несёт два реальных риска. Сохранён здесь на случай,
если решение по провайдеру снова изменится.

## Почему отложен

1. **Приватность (главная причина).** У бесплатного тарифа Gemini контент используется для
   обучения моделей (указано в прайсинге явно: free tier — «used to improve products: Yes»,
   paid — «No»). Это прямо противоречит принципу «финансовые данные не покидают контроль
   пользователя» — весь смысл ассистента в том, чтобы отправлять туда балансы, долги,
   зарплату, историю операций. Митигация (описана ниже) — псевдонимизация на границе
   клиент↔сервер, но она не закрывает риск полностью (названия мерчантов должны идти как
   есть, иначе ломается «сколько я потратил в Korzinka»).
2. **Нестабильность API.** На момент исследования (август 2026) у Gemini произошла смена
   API-поверхности — legacy `generateContent`/`functionCall` схема заменена на **Interactions
   API** (GA с июня 2026), с жёстким удалением старой схемы 8 июня 2026. Формат тулов,
   вызовов функций и состояния диалога отличается от того, что описывалось изначально.
   Модель `gemini-3.7-flash` (free-tier) — pro-тир на бесплатном тарифе вообще убрали.
3. **Неизвестные лимиты.** Google больше не публикует точные RPM/RPD для бесплатного тарифа
   в документации — только «смотрите в AI Studio для своего проекта». Весь дизайн лимитов
   ниже калиброван на неизвестный потолок и требует живой проверки перед запуском.

## Если решение снова изменится — что нужно сделать иначе, чем в Anthropic-плане

### Эндпоинт и модель

```
POST https://generativelanguage.googleapis.com/v1beta/interactions
x-goog-api-key: $GEMINI_API_KEY
Api-Revision: 2026-05-20   (закрепить явно — не полагаться на дефолт)
```
Модель: `gemini-3.7-flash` (или `gemini-3.5-flash-lite` как фолбэк на 429 — не подтверждено,
что у разных id разные квоты, проверить перед тем, как полагаться на это). Использовать
сырой `fetch` в Deno, а не SDK (одна библиотека уже ловила breaking change в этом квартале).

### Системная инструкция и тулы

`system_instruction` — отдельное строковое поле (не `system`, не `systemInstruction`).
Персона/тон/правила («никогда не считать самой, всегда звать тул») — те же, что в
Anthropic-плане.

Объявления тулов — **плоские**, не вложенные в `functionDeclarations`:
```json
{
  "tools": [{
    "type": "function",
    "name": "search_operations",
    "description": "...",
    "parameters": { "type": "object", "properties": { ... }, "required": ["from", "to"] }
  }]
}
```
Тот же набор из 13 тулов (7 read + 6 write), поля не менять — только формат объявления.
Ограничения схемы: подмножество OpenAPI — без `oneOf`/`anyOf`/`$ref`/`allOf`, даты как ISO
строки, закрытые множества — через `enum`.

### Цикл вызова тулов

`store: false` (не Anthropic-подобный `previous_interaction_id`) — сервер по умолчанию
хранит диалог 1 день (free) / 55 дней (paid), но для финансовых данных правильный объём
хранения на стороне третьей стороны — нулевой. Реплей истории — из локальной SQLite, как и
в Anthropic-варианте. **Важно:** в stateless-режиме нужно реплеить `thought`-шаги
дословно — их отбрасывание существенно портит точность вызова тулов у моделей линейки
Gemini 3.x.

### Квоты и деградация

Бюджетировать по **вызовам модели**, не по «вопросам пользователя» — один вопрос с
несколькими раундами тулов — это несколько запросов. Три раздельных сообщения об
исчерпании лимита (свой дневной / общий дневной / RPM) — без модальных ошибок, композер
просто отключается с понятной причиной, история чата остаётся читаемой.

### Псевдонимизация (митигация приватности, независимо от решения по провайдеру)

Поскольку клиент управляет каждым байтом каждого tool-результата, можно токенизировать на
этой границе: счета → `ACC_1`, контрагенты долгов → `PERSON_2`, суммы/даты — как есть
(модель их не считает). Отдельный модуль `src/ai/redact.ts`, применяется к каждому
tool-результату на выходе и обращается на входе. Дешёвая мера, которую сложно добавить
задним числом после того, как 13 тулов уже подключены — если и делать, то сразу.

## Открытые вопросы, если решение вернётся к Gemini

- Реальные RPM/RPD для конкретного проекта — смотреть `aistudio.google.com/rate-limit`
  перед началом реализации, не доверять цифрам из блогов/старой документации.
- Актуальное имя модели на бесплатном/платном тарифе на момент реализации (менялось уже
  минимум раз в 2026).
- Точные имена полей ошибок/safety-блоков — не подтверждены документацией, нужно смотреть
  на живой ответ API.
- Есть ли реально отдельные квоты у `gemini-3.7-flash` и `gemini-3.5-flash-lite` (фолбэк
  предполагает это, не проверено).
