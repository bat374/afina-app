# Афина

MVP мобильного приложения для учёта личных финансов на Expo, React Native и TypeScript.

## Что реализовано

- обзор чистого капитала, доходов и расходов;
- счета: дебетовая и кредитная карты, накопительный счёт, вклад и наличные;
- долги «мне должны» и «я должна»;
- платёжный календарь с прогнозным балансом и кассовым разрывом;
- аналитика, бюджеты и финансовые цели;
- локальное распознавание банковского скриншота через Google ML Kit;
- извлечение типа счёта, банка, баланса, валюты, последних цифр и ставки;
- проверка результата и сохранение распознанного счёта в SQLite.
- условия вкладов: срок, ежедневная, ежемесячная или выплата в конце срока, капитализация или другой счёт;
- автопролонгация и календарное напоминание проверить новую ставку;
- правила снятия: до нуля, до неснижаемого остатка, только проценты или запрет снятия;
- разрешение или запрет пополнения вклада;
- UZS, USD, RUB, EUR, CNY, KZT, AED, GBP и произвольные трёхбуквенные ISO-коды валют;
- расчёт ежедневных, ежемесячных и срочных процентов, события календаря и аналитика пассивного дохода;
- раздельные итоги по валютам без некорректного сложения разных денежных единиц.
- локальная SQLite-база и рабочее создание, редактирование и удаление счетов.
- планирование разовых, ежедневных, еженедельных, ежемесячных и ежегодных расходов;
- изменение ранее созданного разового расхода на повторяющийся, срок окончания повторений и счёт списания;
- автоматический учёт плановых расходов в календаре, прогнозном остатке, кассовых разрывах и аналитике.
- долги «мне должны» и «я должна» с частичным, полным и досрочным погашением;
- пролонгация, ручная и автоматическая просрочка, неизменяемая история событий по долгу;
- автоматическое изменение выбранного счёта при фактическом погашении долга;
- выбираемая базовая валюта, ручные курсы и общий капитал с учётом счетов, дебиторской и кредиторской задолженности.
- автоматическое ежедневное получение официальных курсов из JSON API Центрального банка Узбекистана, пересчёт к выбранной базовой валюте и офлайн-кэш последнего успешного обновления.
- выбор даты расхода из календаря, всплывающий календарь для изменения дат и независимый выбор валюты;
- журнал операций по счетам с фильтрами по валюте, периоду, категории и счёту;
- ручное добавление доходов и расходов с автоматическим изменением баланса счёта;
- месячные бюджеты по категориям и валютам с расчётом фактического использования;
- финансовые цели со сроком и типом: накопить остаток, получить доход за месяц или погасить выбранный долг;
- автоматический процент выполнения цели по актуальным балансам, операциям, процентным доходам и погашениям долга;
- адаптация длинных форм к экранной клавиатуре Android.
- единая форма плановых доходов и расходов: разовые события, стандартные и произвольные интервалы, дни недели и редактирование;
- независимые валюты движения и счёта с автоматическим курсом либо ручным курсом конкретного плана;
- локальная дата «сегодня», автоматическое обновление после полуночи и прогноз только от актуального баланса;
- фактические процентные проводки без дублей: при выплате на тот же счёт баланс увеличивается в SQLite;
- автоматическая ежемесячная дата процентов, перенос пролонгации с выходного и обновление срока;
- редактирование условий долга с записью события в историю и независимая валюта долга;
- календарный выбор дат во всех рабочих формах и ввод сумм с разделителями разрядов.
- кредитные карты: лимит, текущая задолженность, дни выписки и платежа, льготный период, минимальный платёж и ставка;
- напоминание о минимальном платеже по кредитной карте в платёжном календаре без двойного уменьшения общего капитала;
- группировка счетов по типам, фильтры по типу, валюте, банку или названию и группировка долгов по людям;
- средневзвешенная ставка по всем активам в базовой валюте и отдельно по каждой валюте.
- отдельное редактирование условий долга, частичное погашение и выбор счёта для каждого платежа;
- архив полностью погашенных долгов и безопасная отмена ошибочного погашения обратной проводкой;
- сворачиваемые группы счетов с раздельными итогами по валютам;
- финансовые цели с пересчётом всех счетов и доходов в валюту цели;
- периоды аналитики: месяц, квартал, год, всё время и произвольный диапазон через календарь.
- детализированная история изменений условий долга: каждое изменённое поле показывает предыдущее и новое значение;
- защита от повторной отправки при записи погашения долга;
- предпросмотр изменения баланса счёта и подтверждение или ручной ввод курса при погашении долга в другой валюте;
- поиск по архиву погашенных долгов.
- единая история операций: факт и план в одном экране с фильтрами по типу, направлению, валюте, счёту, категории, источнику, статусу и периоду;
- плановые события получают статус (запланировано, просрочено, выполнено, отменено) и не влияют на баланс счёта до проведения;
- проведение планового события создаёт ровно одну фактическую операцию и связывает её с планом без дублей в истории;
- переход из истории к исходному долгу или плану одним нажатием.

Счета, операции, долги, бюджеты, цели и валютные настройки синхронизируются с PostgreSQL в Supabase. Доступ изолирован по `user_id` через Row Level Security. SQLite остаётся офлайн-кэшем: на новом устройстве данные сначала восстанавливаются с сервера, а изменения отправляются в облако после сохранения. Все обращения к локальной базе идут через единую очередь, чтобы параллельные запросы (например, при синхронизации) не конфликтовали друг с другом на Android. Токен сессии хранится через Expo SecureStore. OCR работает локально в установленной APK-сборке; Expo Go не содержит используемый нативный ML Kit модуль.

## Облачная конфигурация

- проект Supabase: `qmaojhymqavvngegeynq`;
- миграции: `supabase/migrations`;
- закрытый bucket документов: `financial-documents`;
- локальная конфигурация: `.env` (не попадает в Git);
- шаблон конфигурации: `.env.example`;
- EAS `preview` и `production` используют `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY`.

В APK разрешён только publishable key. Secret/service-role ключи в приложение и репозиторий добавлять нельзя.

## Запуск

```powershell
pnpm install
pnpm start
```

Затем откройте проект в Expo Go на телефоне или запустите Android/iOS эмулятор.

## Проверки

```powershell
pnpm typecheck
pnpm exec expo export --platform android
```

## Установочный APK

```powershell
npx.cmd eas-cli@latest login
npx.cmd eas-cli@latest build:configure
npx.cmd eas-cli@latest build --platform android --profile preview
```

Профиль `preview` создаёт APK для прямой установки на Android.
